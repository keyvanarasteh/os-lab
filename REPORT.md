# OS-36 Proje Raporu

## Yapılan Çalışma
Bu görev kapsamında sınıf yerel ağındaki (subnet) makinelerin erişilebilirliğini ve SSH servis durumunu kontrol eden linux-lab/scripts/reachability-checker.sh bash scripti geliştirildi. Script ping ile aktif makineleri tespit eder, nc (netcat) aracıyla 22. portun açık olup olmadığını denetler ve isteğe bağlı olarak yerel roster.txt dosyasından isim eşleştirmesi yapar.

## Kazanımlar
VirtualBox üzerinde Ubuntu Server ortamında script geliştirme, dosya izinleri (chmod +x), temel ağ teşhis komutları (ping, nc) ve açık kaynak katkı süreci (fork -> branch -> commit -> push -> Pull Request) öğrenildi.
